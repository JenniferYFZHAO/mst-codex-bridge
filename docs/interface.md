# 接口与证据边界

适配对象为当前已验证的空间结构软件 MST2008（MstCAD.exe）。这是基于导入/导出文件和可见界面的项目桥接，未确认原生 Python、COM 或无界面求解 API。

## 中间模型

机器可读定义见 `model.schema.json`，示例见 `examples/cantilever.json`。节点、杆、材料、截面、支座和工况各有稳定字符串 ID；每次生成 LOG 时按 ID 排序分配 MST 数字编号，映射写入 `mapping.json`。新增 ID 可能改变压缩编号，因此只允许使用同作业映射解释结果。

|数据|单位或约定|
|---|---|
|节点坐标|m，右手系 Z 向上|
|截面尺寸|mm；CHS 为 D/t，RHS 为 b/h/tf/tw，I 为 h/b/tw/tf|
|节点力/力矩|kN/kN·m|
|E、G|MPa|
|密度|kg/m³；GUI 重量密度 = ρ×9.80665/10⁹ N/mm³|
|原生 U 输出|平移 mm，转角 rad|
|源坐标平移转换|(ux,uy,−uz)/1000 m|
|源坐标转角转换|(−rx,−ry,rz) rad；转角为轴矢量|

JSON 禁止额外字段、重复键和非有限数。材料数限定为 1；截面允许不同尺寸；荷载工况限定一个恒载和一个活载。输入校验涵盖引用关系、同端点重复杆、零长杆、孤立节点及无支座连通分量，未代替刚度矩阵秩检查。

## LOG 写入范围

完整 LOG 必须导入新建的空白模型。真实 GUI 试验中，向已带 1 kN 静荷载的模型再次导入 2 kN 完整 LOG，几何更新后静荷载累加为 3 kN；节点与杆件数没有增加，不能据此判断覆盖成功。本包的 edit/prepare 生成完整输入，不生成增量导入命令。重复导入后应另开空白模型重新执行。

|块|规则|
|---|---|
|NODECORD2|`id x y z 1 1`；节点保留六自由度|
|BEAM_ELEMS_7|`id id node_i node_j shape section 0`；本版 α 限定为 0|
|SECTION PROPERTIES|shape、number、10 个尺寸槽、材料 class0、design class1|
|SUPPORT INFORMATION|节点号和六个 1；本版仅写已测全固定|
|DEADLOAD|节点号、Fx、Fy、Fz|
|DEADLOAD1|节点号、Fx、Fy、Fz、Mx、My、Mz；本机力矩探针验证过|
|LIVELOAD|组号、节点号、Fx、Fy、Fz；此顺序与旧说明书有差异，以本机读回为准|

材料 E/G/ν/重量密度作为 GUI 待办输出，不能通过写入 AREAINFO 保证修改。回读以软件生成的 AREAINFO 为准；截面 A/I/J 保留软件实际值。SH5 的 J 与开口四板公式相符，SH20 未确认可覆盖闭口 J。本版不写 AREAINFO 或伪造计算结果。

## 原生结果读取与绑定

公开 LOG 的 U 块舍入较粗。可选高精度读取在配对 GRD 中搜索 N×6 小端 float32 连续数组，扫描 4 个字节相位，以全部 LOG 分量的开放舍入区间约束候选。打印零还约束符号位。全部打印零缺乏定位信息，拒绝推测。多个匹配位置只有在数据字节完全相同时接受。

此能力不构成通用 GRD 格式解析器。它只读文件，核对前后散列，拒绝缺失、顺序不一致、不同候选及扫描期间变化。组合工况块不作为独立数组定位依据。G+Q 可由另行明确系数的独立结果叠加，本版未提供自动组合工具。

`compare` 检查的坐标分量容差为 0.02 mm，截面尺寸约 0.0051 mm，荷载分量为 0.000501 kN 或 kN·m，依据当前 LOG 输出位数保留边界。默认库中未使用截面可多于输入，但所有使用截面须匹配。节点自重开关、求解模式、组合系数仍需界面/专项证据，比较通过不等于验算通过。

定量梁恢复须先完成 `compare → ingest --job --comparison → recover`。比较回执绑定规范化模型、输入 LOG、完整 ID 映射、原生 LOG；读回回执再绑定输出 CSV。recover 重核 CSV 与模型散列，拒绝同编号但不同长度/荷载的模型、错置映射、被编辑 CSV，以及仅来自粗精度 LOG 的数据。未绑定模型的节点结果仍可导出，用于人工检查，不能直接进入本包的定量梁场恢复。

## 数据来源

本项目代码复用本地先前试验中已审计的文件映射规则与受约束读取算法。软件手册、商业安装包、工程源模型及项目计算数据均未纳入可发布源码包。`work/` 属于本机试验区，默认排除。测试中的二进制数组为人工构造，测试不能替代真实 MST 求解；真实 GUI 验证记录单独标注。
