# MST 结构建模工作流

本技能依赖独立 Python 后端。优先使用用户指定的仓库路径或环境变量 `MST_CODEX_BRIDGE_ROOT`，其次检查当前目录及 `mst-codex-bridge/` 子目录。确认 `pyproject.toml` 的项目名为 `mst-codex-bridge`，读取同目录 `README.md` 和 `docs/interface.md`。该环境变量仅提供路径线索，不会扩大 CLI/MCP 工作区读写范围。

缺少后端时，从 https://github.com/JenniferYFZHAO/mst-codex-bridge 克隆到新的目录，按 README 创建 `.venv` 并安装依赖；禁止覆盖已有仓库。仅安装此 Skill 文件夹不会安装后端或 MST。后端安装完成后先运行合成示例 `validate`；真实求解还需要用户本机可用的 MST 和当前环境支持的桌面操作工具。已有 `mst_*` MCP 工具时先核对其工作区，未加载时使用仓库 `.venv` 内 Python 执行同功能 CLI，不能声称当前会话已连接新 MCP。

现有原生模型应先复制到新的作业目录，保留原始文件及散列。技能目录无需复制依赖或模型。

## 文件与桌面的分工

- 文件层使用模型 JSON、Python CLI/MCP、LOG 和映射表；`prepare` 只生成待导入作业。
- 桌面层调用当前环境提供的 computer-use 技能及其受支持工具，观察可见 MST 窗口后完成导入、材料设置、另存、求解和导出。本包不执行隐藏窗口消息、后台 UIA、键盘宏或私有 DLL 调用。
- GUI 成功状态需要实际界面和导出文件共同证明。不要把文件已写出、GRD 已存在、MCP 握手成功解释为求解成功。

## 执行顺序

1. `inspect` / `validate` 确认单位、节点/杆件编号和假定。修改通过 `edit` 的按 ID 补丁，整体校验后写入新目录；每个输出目录只用一次。
2. `prepare` 输出 `model.log`、`mapping.json`、`GUI_STEPS.md`。源坐标为 Z 向上，LOG 已转为 Z 向下；几何 m、截面 mm、荷载 kN/kN·m、弹性模量 MPa。
3. 新建空白 MST 模型后按 `GUI_STEPS.md` 导入和设置。完整 LOG 在已加载模型中重复导入会累加荷载，不能作为覆盖操作；即使节点/杆数量未变也需重建空白作业。材料 E/G/泊松比/重量密度必须在界面确认，`AREAINFO` 输入覆盖不能作为材料或扭转属性已生效的证据。关闭自动自重，采用验算不调整，记录组合系数。
4. 另存 GRD、求解、保存并导出配对 LOG。`compare` 核对几何、支座、截面、荷载及原生材料属性；失败则定位差异，修正副本后再次导入，不叠加未知状态。
5. `ingest --case RESDEADLOAD` 等选择独立工况。带 GRD 时要求全部节点六分量与 LOG 舍入区间匹配，候选数组唯一或字节相同，且前后源文件散列不变。缺失、歧义或全打印零工况按失败处理。准备定量梁场时须提供 `--job` 和该作业通过的 `--comparison`。
6. `recover` 核验同目录 ingestion 回执、CSV 散列、规范化模型散列和高精度来源，拒绝错配模型与仅舍入 LOG 数据。然后由节点六自由度恢复 EB 梁内位移，标注形函数恢复与采样极值；本版不输出连续精确极值，也未包含杆间分布荷载特解。

## 限定范围

当前写入适配仅支持刚接 EB 梁、单材料 class0、CHS/RHS/I 截面、全固定六自由度支座、一个恒载槽和一个活载组。非零截面转角、部分约束、梁端释放及活载力矩需要另建界面探针。本版会拒绝这些输入，不能默默删除。

MST2008 的 SH5 矩形管扭转刚度与闭口管物理值有差异；仅在模型显式接受软件行为时写出。不得声称 AREAINFO 的 J 覆写已得到验证。观察到的版本行为不应推广到全部 MST 版本。

任何输出仍标注 `training_label_release=false`，直到具体研究建立参数、边界、荷载、误差与独立验证准入规则。开源发布须另有用户明确指令；本技能不授权发布商业程序、项目模型或论文。
